# عبدالله ابراهيم محمد — مستشار عقاري أول | Interactive 3D Egypt Real-Estate Portfolio

بورتفوليو تفاعلي ثلاثي الأبعاد وخريطة مشاريع مصر العقارية لـ **عبدالله ابراهيم محمد (`Abdullah Ibrahim Mohamed`) — مستشار عقاري أول (`Senior Property Consultant`)**.

## أبرز المميزات (Key Features)

- **ماكت مصر المعماري ثلاثي الأبعاد (`Three.js`)**: استوديو معماري يظهر فيه المستشار مستندًا على حافة ماكت بارز ثلاثي الأبعاد لخريطة مصر مع إضاءة دافئة وتفاعل بالماوس واللمس، وحركة محكومة بأكشن المستخدم فقط بدون تشغيل تلقائي سلبي.
- **انتقال سينمائي متدرج إلى خريطة مصر التفاعلية (`MapLibre GL JS v6`)**: السكرول أو النقر يغوص بسلاسة من الماكت إلى خريطة مصر الكاملة مع قابلية العودة العكسية في أي لحظة.
- **تغطية موثّقة لـ 6 محافظات استثمارية و22 مشروعًا حقيقيًا**: تبدأ بـ **الإسكندرية** (8 مشروعات كبرى) وتمتد إلى الساحل الشمالي والعلمين، القاهرة الجديدة والعاصمة الإدارية، الشيخ زايد وأكتوبر، البحر الأحمر والجونة، والعين السخنة.
- **ماستر بلان هندسي تفاعلي `2D CAD / 3D Massing`**: الانتقال إلى موقع كل مشروع الفعلي مع تقسيمات مناطق الاستخدام (`5–7` مناطق قابلة للنقر لكل مشروع)، التحويل الفوري بين المسقط الهندسي `2D` والكتل المعمارية البارزة `3D`، مفتاح الأراضي، البوصلة، ومقياس الرسم الحي.
- **تحويل مباشر للاستشارة العقارية (`01280249440`)**: مقارنة حتى 3 مشاريع جنباً إلى جنب، ونموذج حجز استشارة مملوء تلقائيًا بسياق المحافظة/المشروع/المنطقة مع رقم مرجعي (`REQ-YYYY-XXXX`) ورسالة واتساب جاهزة الإرسال، ودعم كامل للغتين العربية (`RTL`) والإنجليزية (`LTR`).

## التشغيل المحلي (Local Development)

```bash
npm install
npm run dev
```

## الاختبارات والبناء (Testing & Production Build)

```bash
npm run typecheck   # فحص الأنواع (TypeScript)
npm test            # اختبارات الوحدات والثوابت الجغرافية (Vitest)
npm run build       # بناء النسخة الإنتاجية
npm run test:e2e    # اختبارات الطرف للطرف (Playwright E2E)
```
